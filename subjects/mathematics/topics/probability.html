Mathematics / Probability

Probability: Understanding Uncertainty.

Probability gives us a mathematical way to describe uncertainty. From tossing a coin to predicting complex events, probability helps us measure how likely something is to happen.

Beginner foundations Interactive experiment Approx. 15 minutes
Overview Events Formula Experiment Practice

1. What is probability?

Probability measures how likely an event is to occur. Its value ranges from 0 to 1.

The probability scale

\(0 \leq P(A) \leq 1\)

A probability of 0 means an event is impossible. A probability of 1 means the event is certain.

Values between them describe different levels of likelihood.

For example, when a fair coin is tossed, there are two equally likely outcomes: heads and tails.

2. Outcomes, sample spaces and events

Before calculating probability, we need to understand what outcomes are possible.

Sample space

The sample space is the complete set of possible outcomes.

\(S=\{H,T\}\)

For a single coin toss, the sample space contains two outcomes: heads and tails.

Event

An event is an outcome, or collection of outcomes, that we are interested in.

For example, getting heads can be represented by:

\(A=\{H\}\)

3. The basic probability formula

When all outcomes are equally likely, probability can be found by comparing the number of favourable outcomes with the total number of possible outcomes.

\[ P(A)= \frac{\text{number of favourable outcomes}} {\text{total number of outcomes}} \]

Example: rolling a die

A standard die has six possible outcomes:

\(S=\{1,2,3,4,5,6\}\)

Suppose we want the probability of rolling a 4. There is one favourable outcome and six possible outcomes.

1 Favourable outcomes = 1
2 Total outcomes = 6
3 Therefore:
\[ P(4)=\frac{1}{6} \]
