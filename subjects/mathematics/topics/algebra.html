01 — The idea

An equation is a balance.

Arithmetic usually asks you to calculate with known numbers. Algebra also lets you work with values you do not know yet. We represent an unknown value with a symbol, often a letter such as x.

Consider this equation. It says that an unknown number, increased by three, gives eight.

x + 3 = 8
Find the value that makes both sides equal.

To find x, we need to undo the addition of three. Subtract three from both sides so that the equality remains true.

Eight minus three is five, so the unknown number is five. We can check the result by putting five back into the original equation.

↳
The central rule: whatever operation you perform on one side of an equation, perform the same operation on the other side.
02 — Follow the method

Solve it one step at a time.

Worked example 3 steps
1
Start with the equation

We know the total, but not the original number.

x + 3 = 8
2
Undo the addition

Subtract 3 from both sides. The left side becomes just x.

x + 3 − 3 = 8 − 3
3
Simplify and check

We get x = 5. Substituting five into the original equation gives 5 + 3 = 8.

x = 5
