Understand your first program

The starter example uses three languages together. Each has a different responsibility, but they work as one small web page.

1. HTML — Build the structure

HTML defines the elements that appear on the page. In the starter example, the heading, paragraphs and button are HTML elements. 

<h1 id="title">Hello, world!</h1>
<p>Welcome to the playground.</p>
<button id="change-button">Click me</button>

Understand this:

  • <h1> creates a main heading.
  • <p> creates a paragraph.
  • <button> creates a clickable button.
  • id gives an element a unique identifier that JavaScript can find.

2. CSS — Change the appearance

CSS controls how HTML elements look. It can change colours, spacing, sizes, borders and page layout. 

h1 {
  color: purple;
}

button {
  background: purple;
  color: white;
  padding: 10px 16px;
}

Here, the heading becomes purple, while the button receives a purple background and white text.

A CSS rule has a selector, followed by properties and their values. For example, color: purple; sets the text colour.

3. JavaScript — Add behaviour

JavaScript allows a page to respond to actions. In this example, it waits for someone to click the button. 

const button = document.querySelector("#change-button");

button.addEventListener("click", () => {
  document.querySelector("#title").textContent = "You did it!";
});

What happens here?

  • document.querySelector() finds an HTML element.
  • const stores a reference to that element.
  • addEventListener() waits for a particular event.
  • "click" specifies that the event is a button click.
  • textContent changes the text displayed inside an element.

4. How the three languages work together

  1. HTML creates the heading and button.
  2. CSS gives those elements their appearance.
  3. JavaScript finds the button and waits for a click.
  4. When clicked, JavaScript changes the heading text.

Pressing Run code updates the preview. Clicking the button inside the preview then triggers the JavaScript event.

Guided experiments

Try these experiments in order. Change the code yourself, run it, and observe what happens.

Experiment 1 — Change the heading

  1. Open the HTML editor.
  2. Find Hello, world!.
  3. Replace it with your own heading.
  4. Press Run code.

Observe: The heading changes, but the page structure remains the same.

Experiment 2 — Change the design

  1. Open the CSS editor.
  2. Find the h1 rule.
  3. Change its color value.
  4. Run the code again.

Observe: The heading's appearance changes without changing its HTML text.

Experiment 3 — Change the button's behaviour

  1. Open the JavaScript editor.
  2. Find the line that changes the heading's textContent.
  3. Replace the message with a sentence of your choice.
  4. Run the code and click the button in the preview.

Observe: The heading changes only after the button is clicked.

Experiment 4 — Inspect the console

  1. Open the JavaScript editor.
  2. Add console.log("My first experiment!"); inside the click event.
  3. Run the code and click the button.
  4. Look at the Console panel.

Observe: JavaScript can display messages in the console without adding them to the web page.

Challenge — Create your own button interaction

Now try making a small change without following the exact example.

  • Change the heading to a title of your choice.
  • Give the button a different background colour.
  • Make clicking the button display the message Experiment complete!
  • Print a confirmation message in the console.

Success criteria: The page displays your heading, the button has your chosen colour, clicking it changes the message, and the console shows your confirmation.

If you change an element's ID in HTML, remember to update the corresponding JavaScript selector too.
